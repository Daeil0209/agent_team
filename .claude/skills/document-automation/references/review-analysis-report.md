# document-automation: Review And Analysis Reports
Use when the document is a risk analysis, condition evaluation, go/no-go report, compliance review, or judgment-delivery memo.

## Persuasion Structure
- Apply "Why -> So What -> Now What" for risk analyses, condition evaluations, and go/no-go reports.
- For short answer-first condition reviews, use answer -> decisive reasons -> actionable conditions.
- Stage 1 `Why` decomposes the topic into 4-6 distinct named categories.
- Each category needs a concrete causal mechanism.
- Category labels alone are a persuasion defect.
- Stage 2 `So What` dedicates a named section to why the target environment amplifies identified risks.
- Generic restatement is a defect.
- Stage 3 `Now What` tiers recommendations by risk level.
- Short answer-first artifacts with one dominant decision path use a single standard path plus bounded exceptions.
- Include case studies when materially available, decision-changing, or explicitly requested.
- Bidirectional framing presents both prohibited actions and required conditions.
- Unidirectional framing is a completeness defect.

## Analysis Depth Techniques
- Causal chain narrates trigger -> mechanism -> immediate consequence -> ultimate outcome within each risk category.
- Stopping at risk label is an analysis-depth defect.
- After primary risks, check for secondary dangers emerging as consequence.
- Stopping at primary risks is a defect.
- When risk is invisible, state the sensory limitation explicitly.
- Sensory limitation examples include colorless or odorless risks.
- When gap data between regulatory requirement and actual practice is available, include it.
- Omission of available regulation-reality gap data in compliance-review reports is a persuasion defect.

## Conclusion Design Techniques
- State an unambiguous decision criterion.
- When competing priorities exist, explicitly declare which takes precedence.
- When the reader's situation is undetermined, state a conservative-design principle.
- For legal or regulatory tables, add a column translating each item into the reader's specific context.
- Optimal length test: removing anything loses a critical argument.
- Apply impact-per-page test before finalizing.

## Resolve Next Owner And Action
- Return analysis structure, decision criterion, risk-tier logic, bidirectional framing, and conclusion test results to the active document-automation workflow.
- If evidence boundary, risk tiering, or decision criterion is under-specified, route the named gap before final prose generation continues.
