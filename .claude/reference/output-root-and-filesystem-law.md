## Output-Root Rules
- Task-created deliverables stay under the task project folder.
- Task-created evidence stays under the task project folder.
- Task-created logs stay under the task project folder.
- Task-created exports stay under the task project folder.
- Tool output stays under the task project folder unless another canonical root is frozen.
- Place generated products outside repo root unless repo root is the frozen output root.
- Place generated products outside `.claude/*`.
- Place generated products outside runtime state.
- Place generated products outside home.
- Place generated products outside temp.
- Place generated products outside incidental cwd.
- If the project output folder is unknown, derive and freeze the safest canonical root.
- User escalation is invalid when a safe canonical root exists.
